## Bobby - A slackbot with 3 commands to do silly things! 

This is quite a basic slackbot and uses API's from https://docs.thecatapi.com/ and https://uselessfacts.jsph.pl/ ! 

It has 3 basic commands: 
- /bobby-ping : Checks if the bot is running and it's latency 
- /bobby-fact-of-the-day : Gives a random fact that refreshes daily!!!
- /bobby-catpics : Gives a random cat pic, who doesn't love cats 

I made it mainly because this was my first slackbot, atleast my first slackbot that hasn't been vibecoded entirely and I was curious how a slackbot works because I use it daily :D 

Uses Node.js 18+ 

AI usage on this is very limited - I have used it only for debugging as I haven't touched JS in a while and don't use it much.
